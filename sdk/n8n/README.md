# n8n-nodes-clrd

Send notifications, change their state, and trigger n8n workflows on clrd
events. The package is unpublished. Build and install from source with
the [n8n guide](https://github.com/thejdubb02/clrd/blob/main/docs/integrations/n8n.md).

Send can include icons, file links and copy actions. Set External ID to update
an open notification and select Updated Notification to trigger on edits.
