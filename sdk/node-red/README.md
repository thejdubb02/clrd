# node-red-contrib-clrd

Send notifications, change their state, and trigger Node-RED flows on clrd
events. The package is unpublished. Build and install from source with
the [Node-RED guide](https://github.com/thejdubb02/clrd/blob/main/docs/integrations/node-red.md).

Send objects can include icons, file links and copy actions. Reuse
`external_id` to update an open notification and select Updated Notification
to trigger on edits.
