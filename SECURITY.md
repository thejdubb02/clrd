# Security policy

## Reporting a problem

Please report security problems privately through GitHub:
[Report a vulnerability](https://github.com/thejdubb02/clrd/security/advisories/new).
Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with
it. You will get a reply within 7 days. Once a fix ships, the advisory is
published with credit to you unless you prefer otherwise.

## Supported versions

clrd has no tagged release yet. Fixes land on `main`. Once releases start, the
latest release gets security fixes.

## Scope

The server, web inbox, Android app, SDKs and GitHub Action in this repository.
Problems in a reverse proxy or host you run clrd behind are out of scope, but
tell us if our docs recommend something unsafe.
